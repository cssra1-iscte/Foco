# Foco

App pessoal para gerir tarefas, eventos, objetivos e rotinas, agrupados por áreas da vida, com calendário.

- **Rotinas**: hábitos com dias da semana, ligados a objetivos, com estatísticas de dias praticados, sequência atual e melhor sequência, cumprimento e histórico.
- Abre no telemóvel e usa **Adicionar ao ecrã principal** para a instalar como app.
- Os dados ficam guardados no próprio dispositivo (localStorage). Usa **Cópia de segurança** no ecrã inicial para exportar e importar.
- Sem dependências nem build: HTML, CSS e JavaScript num só ficheiro (`index.html`), mais `manifest.webmanifest` e `sw.js` para funcionar como PWA e offline.
